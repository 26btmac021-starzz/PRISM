# PRISM ESP32 Firmware

Firmware for the PRISM disaster-management and early-warning prototype.

## Responsibilities
- Read environmental sensors
- Process and validate sensor readings
- Transmit readings to the backend
- Control local LEDs and buzzer alerts
- Support future LoRa and 4G integration

## Development
- Platform: ESP32
- Framework: Arduino
- Language: C++

Hardware integration will be completed after the components are available.
